
# 🌸 Siyabah Yasmin Accounting App

**সিয়াবাহ ইয়াসমিন অ্যাকাউন্টিং অ্যাপ** একটি সহজ ও ব্যবহারবান্ধব অনলাইন হিসাবরক্ষণ অ্যাপ। এটি ব্যবসার পণ্য, বিক্রয়, খরচ, লাভ-ক্ষতি এবং অন্যান্য হিসাব পরিচালনার জন্য তৈরি।

## ✨ Features

- 📊 Dashboard থেকে ব্যবসার হিসাব দেখা
- 📦 পণ্য যোগ, সম্পাদনা ও মুছে ফেলা
- 🧾 বিক্রয় ও অর্ডারের হিসাব সংরক্ষণ
- 💰 লাভ-ক্ষতির হিসাব
- 📢 বিজ্ঞাপন খরচ সংরক্ষণ
- 🔄 Delivered ও Returned অর্ডারের হিসাব
- ☁️ Firebase Firestore-এ অনলাইন ডেটা সংরক্ষণ
- 🌸 আকর্ষণীয় ও ব্যবহারবান্ধব ডিজাইন
- 🖼️ অ্যাপের লোগো পরিবর্তনের সুবিধা
- ✏️ অ্যাপের নাম পরিবর্তনের সুবিধা

## 🛠️ Technologies

- HTML5
- CSS3
- JavaScript
- Firebase Authentication Services
- Firebase Firestore
- GitHub Pages

## ☁️ Database

এই অ্যাপ Firebase Firestore ব্যবহার করে অনলাইনে তথ্য সংরক্ষণ করে।

**Firestore Collections:**
- `products`
- `entries`
- `settings`

## 🔒 Data & Security

অ্যাপের ডেটা Firebase Firestore-এ সংরক্ষিত হয়। ডেটার নিরাপত্তা নিশ্চিত করতে Firebase Security Rules সঠিকভাবে কনফিগার করা জরুরি।
