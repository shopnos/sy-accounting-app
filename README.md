# 🌸 সিয়াবাহ ইয়াসমিন — প্রিমিয়াম ক্যাশফ্লো অ্যাপ

এটি একটি কাস্টম-বিল্ট, মোবাইল-রেসপন্সিভ ক্যাশফ্লো (Cashflow) ট্র্যাকিং অ্যাপ্লিকেশন, যা মূলত রিসেলিং বিজনেসের হিসাব সহজ করতে ডিজাইন করা হয়েছে। এতে প্রোডাক্টের ক্রয়মূল্য, এড কস্ট, ডেলিভারি চার্জ এবং রিটার্নের হিসাব একদম নিখুঁতভাবে ট্র্যাক করা যায়।

অ্যাপটিতে ব্যবহারকারীর অভিজ্ঞতা বাড়ানোর জন্য একটি সুন্দর **মেয়েলি পিংক-পার্পল (Pink-Purple) ফ্লোরাল ডিজাইন** এবং অ্যানিমেটেড ফুলের নকশা ব্যবহার করা হয়েছে।

---

## ✨ মূল ফিচারসমূহ (Key Features)

*   **সিম্পল লগইন:** কোনো পাসওয়ার্ড বা ইমেইল ছাড়াই শুধু মোবাইল নম্বর দিয়ে অ্যাপে প্রবেশ করা যায়।
*   **রিয়েল-টাইম ড্যাশবোর্ড:** মোট অর্ডার, প্রফিট, লস, গড় এড কস্ট এবং সাকসেস রেট এক নজরে দেখা যায়। সামগ্রিক বা নির্দিষ্ট প্রোডাক্ট অনুযায়ী হিসাব ফিল্টার করা যায়।
*   **স্মার্ট অর্ডার এন্ট্রি:** প্রোডাক্ট সিলেক্ট করলেই এড কস্ট অটোমেটিক বসে যায়। ম্যানুয়াল কাজ কমাতে ফর্মটি ডিজাইন করা হয়েছে।
*   **অর্ডার হিস্ট্রি ও সার্চ:** সব অর্ডারের তালিকা, স্ট্যাটাস অনুযায়ী ফিল্টার এবং কাস্টমারের নাম বা মোবাইল দিয়ে সার্চ করার সুবিধা।
*   **মাস্টার ডাটা ম্যানেজমেন্ট:** নতুন প্রোডাক্ট যোগ করা এবং প্রোডাক্টের ক্রয়মূল্য বা এড কস্ট এডিট করার সুবিধা (এডিট করলে ড্যাশবোর্ডের সব হিসাব সাথে সাথে আপডেট হয়)।
*   **অ্যাপ সেটিংস:** প্রতিষ্ঠানের নাম এবং লোগো পরিবর্তন করার অপশন, যা ফায়ারবেসের (Firebase) সাথে সিঙ্ক থাকে। লিংক ব্যবহারকারী সবাই এই পরিবর্তন দেখতে পায়।

## 🧮 হিসাবের ফরমুলা (Calculation Logic)

এই অ্যাপটি রিসেলিং মডেলের ওপর ভিত্তি করে হিসাব করে:

*   **গড় এড কস্ট (Avg Ad Cost):** `মোট এড খরচ ÷ মোট অর্ডার সংখ্যা`
*   **প্রফিট (Delivered):** `বিক্রয়মূল্য - (ক্রয়মূল্য + গড় এড কস্ট)`
*   **লস (Returned):** `গড় এড কস্ট + রিটার্ন ডেলিভারি চার্জ` *(শুধুমাত্র যদি ফর্মে টিক দেওয়া হয় যে রিটার্ন চার্জ কাস্টমার দেয়নি, অর্থাৎ লস আপনার)*

## 🚀 কীভাবে চালাবেন (How to Run)

১. **Firebase সেটআপ:** কোডের ভেতরে `firebaseConfig` অবজেক্টে আপনার ফায়ারবেস প্রজেক্টের API Key, Auth Domain এবং Project ID বসাতে হবে।
২. **হোস্টিং:** `index.html` ফাইলটি GitHub Pages, Netlify বা Firebase Hosting-এ আপলোড করলেই অ্যাপটি লাইভ হয়ে যাবে।
৩. **আপডেট:** যেকোনো কোড পরিবর্তন করলে সরাসরি `main` ব্রাঞ্চে না দিয়ে নতুন ব্রাঞ্চে টেস্ট করার পর মার্জ করা উচিত।

## 📱 ব্যবহারবিধি (How to Use)

1.  প্রথমে **মাস্টার ডাটা** ট্যাবে গিয়ে আপনার প্রোডাক্টের নাম, ক্রয়মূল্য এবং মোট এড খরচ যোগ করুন।
2.  এরপর **হোম (Home)** ট্যাব থেকে নতুন অর্ডার এন্ট্রি করুন (কাস্টমারের নাম, প্রোডাক্ট, বিক্রয়মূল্য এবং স্ট্যাটাস দিন)।
3.  অর্ডারের স্ট্যাটাস পরিবর্তন করলে ড্যাশবোর্ডে অটোমেটিক প্রফিট বা লস আপডেট হয়ে যাবে।
4.  যেকোনো অর্ডার এডিট বা ডিলিট করতে **অর্ডার লিস্ট** ট্যাবে যান।
